# DarkRune Open Dev Plugins

Исходный код открытых Minecraft-плагинов от **DarkRune Dev**.
Современные, производительные плагины для Paper / Folia 1.21+.

> English version: [README.md](README.md)

---

## Плагины

| Плагин | Описание | Статус | Документация |
|---|---|---|---|
| **DarkRune Tab** | Таб-лист, неймтеги, скорборд, чат | Pre-release | [EN](DarkRune-Tab/README.md) / [RU](DarkRune-Tab/README-RU.md) |

Список будет пополняться. Каждый плагин — в отдельной папке со своими
исходниками, README, примером конфига и копией лицензии.

---

## Общие требования

- Java 21+
- Paper / Folia 1.21+
- LuckPerms (опционально)
- PlaceholderAPI (опционально)

---

## Сборка

Каждый плагин — отдельный Maven-проект:

```bash
cd <папка-плагина>
mvn clean package
```
