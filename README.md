# DarkRune Open Dev Plugins

Исходный код открытых Minecraft-плагинов от **DarkRune Dev**.
Современные, производительные плагины для Paper / Folia 1.21+.

> English summary: Source code of open-source, high-performance Minecraft
> plugins for Paper / Folia 1.21+ by DarkRune Dev.

---

## Плагины

| Плагин | Описание | Статус | Документация |
|---|---|---|---|
| **DarkRune Tab** | Таб-лист, неймтеги, скорборд и форматирование чата | Pre-release | [README](DarkRune-Tab/README.md) |

Список будет пополняться. Каждый плагин лежит в отдельной папке
со своими исходниками, README, примером конфига и копией лицензии.

---

## Общие требования

- Java 21+
- Paper / Folia 1.21+
- LuckPerms (опционально, для префиксов/сортировки)
- PlaceholderAPI (опционально, для внешних плейсхолдеров)

---

## Сборка

Каждый плагин — отдельный Maven-проект:

```bash
cd <папка-плагина>
mvn clean package
```

Готовый JAR появится в `target/`.
